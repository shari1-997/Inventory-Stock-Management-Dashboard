# Contributing

Thank you for your interest in improving this project.

Useful contributions may include:

- Improving Excel formulas or validation logic
- Improving dashboard usability
- Adding useful inventory metrics
- Improving documentation
- Identifying reproducible workbook issues
- Suggesting clearer visualizations

## Before Submitting

1. Clearly describe the proposed change.
2. Explain the reason for the change.
3. For workbook changes, verify that KPIs and PivotTables still reconcile.
4. Include screenshots when a visual/dashboard change is involved.

## Pull Requests

Keep pull requests focused on one improvement whenever possible. Describe what changed and how it was validated.
